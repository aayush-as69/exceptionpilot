# AI agent

Only the mock provider is implemented. It is honestly labeled `deterministic-rules-v1`. It reads invoice, PO, GRN, vendor history, active policy evidence, duplicate indicators, and deterministic variance/risk results. Its report contains findings labeled FACT or RULE_BASED_RECOMMENDATION, evidence references, match checks, risk factors, recommendation, approval requirement, empty actions-taken list, and null uncalibrated confidence. It stores no chain-of-thought. It can investigate while approval is pending without changing that approval state. The agent has no executable financial tool authority. Tool levels L0–L3 are documented in the registry; prohibited operations have no handler. OpenAI/Gemini are not connected or simulated. Latency is measured; external tokens and cost remain zero. The copilot uses structured queries and real evidence, refuses override instructions, and fails visibly.
