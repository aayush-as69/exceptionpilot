# Database

Schema: src/db/schema.ts. Migration: drizzle/0000_option_b.sql; append-only trigger: drizzle/0001_append_only_audit.sql. Financial values use integer paise, avoiding floating-point totals. Tolerance comparisons cross-multiply before comparison. Foreign keys and indexes cover vendor, owner, status, risk, deadline, document, and audit lookup. Session tokens are digests. Line items are typed JSONB rather than separate item tables. Document versions are separate document rows; the policy points to the active source while old sources are archived. Audit before/after values provide configuration history, not a complete financial temporal database. Use scripts/migrate.ts on a fresh database. The preview was push-bootstrapped and had the audit guard applied separately; do not blindly replay the initial migration over it.
