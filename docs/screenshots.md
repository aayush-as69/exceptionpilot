# Screenshots

The repository currently contains no captured runtime screenshots.

This page defines the visual documentation set so screenshots can be added without changing the README structure.

## Required screenshots

### 01 — Overview

Capture the default workspace showing headline metrics, priority queue, risk distribution, activity, vendor watchlist, and navigation.

Suggested filename: `docs/screenshots/01-overview.png`

### 02 — Investigation

Open `/?exception=EXC-1042` and capture PO/invoice/GRN comparison, variance, risk factors, investigation result, and Evidence & policy.

Suggested filename: `docs/screenshots/02-investigation.png`

### 03 — Approval

Capture the approval request and decision confirmation showing requester, approver, authority check, evidence confirmation, and approve/reject controls.

Suggested filename: `docs/screenshots/03-approval.png`

### 04 — Audit

Capture the resolved case showing audit timeline, before/after state, communication draft, evidence export, and resolution feedback.

Suggested filename: `docs/screenshots/04-audit.png`

## Screenshot standards

Use the same browser width for every image, preferably 1440px.

Keep screenshots free of personal credentials and real financial data. Keep them focused, readable at GitHub README width, and consistent in theme.

Once captured:

```markdown
![Overview](docs/screenshots/01-overview.png)
![Investigation](docs/screenshots/02-investigation.png)
![Approval](docs/screenshots/03-approval.png)
![Audit](docs/screenshots/04-audit.png)
```

Do not use fabricated screenshots as evidence of functionality.
